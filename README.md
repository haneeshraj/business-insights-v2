# Business Insights v2

Find a business's name, logo, merchant category code (MCC) and headquarters address from its website. It's built for bank teams that do merchant onboarding, KYB, merchant risk and transaction enrichment.

> **Status:** early development. The package structure and tooling are in place; the analysis pipeline isn't built yet.

v2 is an open-source terminal app: you install it, add your own API keys, and run it on your own machine. A demo website for trying it in a browser comes later.
