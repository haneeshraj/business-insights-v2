# Business Insights v2

Find a business's name, logo, phone number, email address, social media links, merchant category code (MCC) and headquarters address from its website. It's built for bank teams that do merchant onboarding, KYB, merchant risk and transaction enrichment.

> **Status:** early development. The name, logo, phone number, email address and social media links work today, from rules alone with no AI. The MCC, the headquarters address and the AI pass, with Jev and LLMs for the answers the rules aren't sure of, come next.

v2 is an open-source terminal app: you install it, add your own API keys, and run it on your own machine. A demo website for trying it in a browser comes later.
